# Water Diplomacy Handbook

Static public website for
[waterdiplomacyhandbook.com](https://waterdiplomacyhandbook.com/), serving
the open-access _Routledge Handbook of Water Diplomacy_.

This repository is the GitHub Pages deploy repository. It intentionally contains
only the files needed to serve the public site and support discovery,
attribution, and maintenance.

## Contents

- `index.html` - homepage
- `brief-overview/` - brief overview
- `key-themes/` - key themes
- `explore/` - role- and topic-based reading pathways
- `chapters/` - complete table of contents with chapter DOIs
- `foreword/`, `detailed-overview/`, `contributors/`, `acknowledgments/`
- `assets/images/cover/` - cover image assets used by the site and social cards
- `data/chapters.json` - public chapter metadata used for validation
- `sitemap.xml`, `robots.txt`, `CNAME`, `.nojekyll`, `404.html`

## Analytics

The site uses Cloudflare Web Analytics, configured as a cookie-free,
privacy-preserving analytics beacon. It does not use local cookies or
`localStorage` in this site code.
